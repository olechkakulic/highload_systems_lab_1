# Демонстрация и работа команды

## Что показать преподавателю

1. Схему БД из `architecture.md`: объяснить три обязательных вида связей.
2. `docker compose up --build -d --wait`, healthchecks, единую Swagger UI.
3. Создание приюта, двух заявителей, животного с тегами и двух заявок.
4. Ошибку повторной активной заявки, одобрение одной заявки, передачу животного. Проверить `ADOPTED`, `COMPLETED`, `REJECTED`.
5. Создание смены вместимостью 1 и двух волонтёров. Первый записывается, второй получает `409`; после отмены первого место снова доступно.
6. Каталог животных с `X-Total-Count`; список смен с `hasNext` и без общего количества. Запрос `size=51` получает `400`.
7. Ошибки неверных полей и несуществующих записей.
8. `./mvnw clean verify` и HTML-отчёт JaCoCo; отдельно показать конкурентные тесты и тест отката.
9. Объяснить, зачем транзакциям нужны блокировки родительских записей.
10. Показать feature-ветку и Conventional Commits в `git log --all --graph --oneline`.

`python3 scripts/demo.py` автоматически проходит основные сценарии, оставляя данные для просмотра в Swagger.

## Разделение на двух участников

| Участник 1 | Участник 2 |
|---|---|
| Животные, теги, заявки, передача | Приюты, пользователи, смены, участие |
| Каталог с общим количеством | Список смен без общего количества |
| Сценарии и тесты своей части | Сценарии и тесты своей части |
| Основа сборки, ошибки, тестовая инфраструктура | Docker, env, Flyway, Swagger |

Оба должны понимать схему БД, правила статусов и формат API. При дальнейшем развитии каждый добавляет Entity/DTO/repository/service/controller/миграции/тесты для законченной функции. Перед слиянием второй участник проверяет изменения.

## Что требует участия людей

- Согласование модели с преподавателем: готовые ER-диаграмма и SQL являются материалом для согласования, а не подтверждением его прохождения.
- Взаимный review и защита: автоматические тесты проверяют поведение, но не заменяют объяснение решений участниками.
- Удалённый репозиторий команды: локальная история уже создана, URL для push команда выбирает самостоятельно.
